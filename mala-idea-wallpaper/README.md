# Mala Idea Wallpaper

An idle screen for the XDJ-AZ (AZ-MODS core 1.2.3+) with the Mala Idea logo in white
ASCII art. When nothing is touched and no deck plays for the chosen time (Mod Menu >
Mala Idea Wallpaper > Show after), it covers the screen; a touch, a browse-knob turn, or
loading or playing a track brings the deck back. The touch that closes it never reaches the
deck.

The picture is `assets/wallpaper.miw`, drawn by `../tools/make_wallpaper.py`.

See the [repository README](../README.md) to build, test and publish it.
